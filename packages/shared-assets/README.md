## M3.5 derivatives and model studies

Responsive AVIF art, portrait mobile valley and smaller transparent wordmarks are recorded in m3-5-derivatives.json and m3-5-priority-assets.json. The two preparation scripts read committed derivatives and do not require access to game sources. Cinzel's 25,904-byte Latin variable WOFF2 and optional 14,540-byte extended subset are from @fontsource-variable/cinzel 5.3.0; the exact OFL is included as licenses/Cinzel-Fontsource-OFL.txt. The former full TTF is no longer transferred. Current English display uses Latin/extended Latin; Cyrillic display is not claimed.

User-identified permanent Blender source masters under D:/Caelora-source-assets/Bonds supply the falcon and wolf. Exact paths, SHA256, triangle counts, render treatment, optimized image dimensions and rights limits are recorded in m3-5-model-studies.json. They are existing high-density source models (approximately3.18M and2.34M triangles), not browser-ready game meshes. Blender5.2.2 renders were made offline with transparent backgrounds and packed textures; no source .blend was saved or copied into this repository. Only640/960px square WebP derivatives are distributed in the website. The page labels them '3D model study · Not gameplay'. This does not claim taming/companion gameplay is playable.

Recreate locally with Blender in background/disabled-autoexec mode, loading the source .blend and running scripts/render-model-study.py with an output PNG path after `--`. The script does not save the loaded Blender file. Put renders at artifacts/m3-5/renders/falcon.png and wolf.png, then run node scripts/prepare-model-studies.mjs. These workstation-only sources are optional; ordinary clones build entirely from committed web derivatives. Commercial provider/plan redistribution rights remain unverified and require publisher confirmation before public release.
